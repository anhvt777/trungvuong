Thử nghiệm đồng bộ giao dịch Trưng Vương

Công cụ kiểm thử riêng, không phải phần thu tiền thật. Công cụ chỉ đọc bảng tham chiếu 60 khoản thu giả lập đã tải từ Cloudflare; không tự gửi dữ liệu đi. Một giao dịch thử sẽ được xuất thành JSON để duyệt trên cổng phụ huynh. Không dùng dữ liệu học sinh thật.

Về web quản lý trường Trưng Vương

1. Chuẩn bị bảng tham chiếu

Tải file TRUNGVUONG_PORTAL_CHARGE_REFERENCE_PRIVATE.json từ Cloudflare Access

Không chọn file TRUNGVUONG_PARENT_DRAFT_...json. File đó là danh sách học sinh và khoản phải thu, không chứa giao dịch đã nộp.

2. Tạo một giao dịch giả lập


  

  

    
3. Duyệt lô trên Cloudflare

    
Sau khi đã tải file TRUNGVUONG_PAYMENTS_MAPPED_DRAFT_...json, mở trang duyệt lô, chọn đúng file vừa tạo, đọc kết quả PREVIEW, rồi mới quyết định ghi dữ liệu giả lập.
